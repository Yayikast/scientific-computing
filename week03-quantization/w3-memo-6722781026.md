1. q4_K_M is 397MB, ~40% the size of the uncompressed model (994MB), which matters on an 8GB laptop with limited memory. q4_K_M runs faster, ~285.4 tokens/s vs ~185.8 tokens/s for the uncompressed model, which matters on a device with no dedicated graphics processor.

## Glossary

**q4_K_M / q2_K** -> Quantized versions of the same AI model. Compression means the model's internal numbers are stored with less precision, which shrinks the file and speeds it up, at some risk to accuracy. The "4" and "2" refer to how aggressively each version is compressed; q2_K is the more heavily compressed.

**Tokens/s (tokens per second)** -> How fast the model generates text, higher means faster responses.

**Cosine similarity** -> A score from 0 to 1 showing how closely 2 outputs match; 1 means they're identical.

**Block-based compression** -> A method of compressing the model in small groups of numbers at a time, rather than all at once, which helps preserve accuracy.
